# MedCare Multispeciality Hospital — Website

A professional, responsive hospital website built with clean HTML, CSS and JavaScript in a single self-contained `index.html` (images embedded, so it runs anywhere with zero setup).

## Live sections
- Sticky header + top info bar with 24x7 emergency contact
- Hero with trust points and hospital photo
- Stats band, 8 department cards with professional SVG icons
- About the hospital with facilities
- Doctor profiles (3 specialists) with OPD timings — "Book Appointment" prefills the form
- Why choose us, patient testimonials
- Appointment booking form with validation and success state
- Visiting hours, contact cards and a complete footer

## Design
Editorial, premium design system: deep teal + white palette, Fraunces display font with Inter body text, 8-point spacing rhythm, soft shadows, fully responsive (mobile menu included). No gradients, no neon, no clutter.

## Note
Demonstration website — hospital name, doctors and details are illustrative.
